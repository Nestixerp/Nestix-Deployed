1 Overview & How the Engine Works

The Press Brake quoting engine estimates how many seconds it takes to bend one part, then converts that time into a dollar cost using the operator's hourly rate.

The calculation has 12 steps that build up from a base bend time, applying modifiers for material thickness, tooling, weight, geometry, and difficulty. The result is seconds-per-part, which becomes dollars-per-part.

Master Formula:
Cost per Part = (Final Seconds ÷ 3600) × Hourly Rate + (Setup Cost ÷ Quantity)

Every field described below is either an input field (operator types a value) or a calculated field (FileMaker computes it automatically).

4 Step 1: Base Bend Time

Purpose: Determine how many seconds one single bend takes before any modifiers are applied. Based entirely on the length of the bend.

FileMaker Calculation — c_BaseBendTime Case ( BendLength_mm > 2000 ; 45 ; BendLength_mm > 1000 ; 30 ; BendLength_mm > 500 ; 20 ; 15 )
Why bend length matters: A 400mm bend — the operator positions the part against the back gauge quickly. A 2500mm bend — the operator must walk along the machine, support the sheet, and ensure it doesn't sag. Hence 3× the time.

5 Step 2: Thickness Factor

Purpose: Thicker material requires slower ram speed, more force, and more springback compensation. This multiplier increases the bend time accordingly.

FileMaker Calculation — c_ThicknessFactor Case ( Thickness_mm > 10 ; 1.50 ; Thickness_mm > 6 ; 1.30 ; Thickness_mm > 2 ; 1.15 ; 1.00 )

6 Step 3: V-Die Size & V-Die Factor

Step 3a: V-Die Size

Purpose: The V-Die opening is the groove in the bottom tool. Industry standard is 8 × material thickness. The operator can override this if a non-standard die is needed.

FileMaker Calculation — c_VDieSize_mm Case ( ManualVDie_yn = "Yes" and ManualVDie_mm > 0 ; ManualVDie_mm ; Thickness_mm * 8 )
The 8× Rule: A 3mm thick sheet uses a 24mm V-Die (3 × 8 = 24). This gives the best balance of bend quality, minimum tonnage, and acceptable inside radius. A smaller V-Die gives a tighter radius but needs more tonnage. A larger V-Die reduces tonnage but produces a larger radius.

Step 3b: V-Die Factor

Purpose: Larger V-Dies require slower ram approach and more careful alignment, adding time.

FileMaker Calculation — c_VDieFactor Case ( c_VDieSize_mm > 40 ; 1.35 ; c_VDieSize_mm > 24 ; 1.20 ; c_VDieSize_mm > 12 ; 1.10 ; 1.00 )

7 Step 4: Bend Time per Bend

Purpose: Combine the base bend time with both modifiers to get the actual time for one single bend.

Bend Time = Base Bend Time × Thickness Factor × V-Die Factor
FileMaker Calculation — c_BendTime c_BaseBendTime * c_ThicknessFactor * c_VDieFactor

Example: 1600mm bend, 3mm thick, V-Die = 24mm
= 30 sec × 1.15 × 1.10 = 37.95 seconds per bend

8 Step 5: Forming Time

Purpose: Total time spent actively bending the part. Simply the single bend time multiplied by the number of bends.

Forming Time = Bend Time × Number of Bends
FileMaker Calculation — c_FormingTime c_BendTime * NumberOfBends

Example: 37.95 × 4 bends = 151.8 seconds

9 Step 6: Handling Time (Weight)

Purpose: Heavy parts are slower to load onto the machine, position against the back gauge, and remove after bending. This adds a flat number of seconds per part.

Auto-Weight Calculation (if weight not manually entered)

FileMaker Calculation — c_AutoWeight_kg Let ( [ density = Case ( Material = "Stainless Steel" ; 8000 ; Material = "Aluminium" ; 2700 ; 7850 ) ; volume_m3 = ( PartLength_mm / 1000 ) * ( PartWidth_mm / 1000 ) * ( Thickness_mm / 1000 ) ] ; Round ( volume_m3 * density ; 2 ) )
Use the higher value: If operator enters PartWeight_kg manually, use that. Otherwise use c_AutoWeight_kg. In FileMaker: If ( PartWeight_kg > 0 ; PartWeight_kg ; c_AutoWeight_kg )
FileMaker Calculation — c_HandlingTime Let ( w = If ( PartWeight_kg > 0 ; PartWeight_kg ; c_AutoWeight_kg ) ; Case ( w > 25 ; 30 ; w > 15 ; 20 ; w > 10 ; 10 ; w > 5 ; 5 ; 0 ) )

10 Step 7: Flip Time

Purpose: When bends go in different directions (e.g., up then down), the operator must flip the part. Longer parts are harder to flip. Time = number of flips × time per flip.

FileMaker Calculation — c_FlipTime Let ( flipTimePer = Case ( BendLength_mm > 2000 ; 12 ; BendLength_mm > 1200 ; 8 ; BendLength_mm > 500 ; 5 ; 3 ) ; FlipsPerPart * flipTimePer )

Example: 2 flips on a 1600mm part = 2 × 8 = 16 seconds

11 Step 8: Box / Complex Geometry Penalty

Purpose: When forming a box (4-sided tray) or complex shape, the last bend is significantly harder because the already-formed sides block access to the die. The operator must tilt the part, the back gauge cannot reach, and the ram must approach slowly to avoid crushing the walls.

The penalty is 50% of one modified bend time, applied only for Box and Complex geometry types.

FileMaker Calculation — c_BoxPenalty Case ( GeometryType = "Box" or GeometryType = "Complex" ; c_BendTime * 0.5 ; 0 )

Example: Geometry = "Box", Bend Time = 37.95 sec
Box Penalty = 37.95 × 0.5 = 18.975 seconds

Geometry types that do NOT get the penalty: Flange, Channel, Hat, Z-Bend. These have open access on the last bend.

12 Step 9: Part Time (Subtotal)

Purpose: Sum all the time components into a single subtotal before applying difficulty and operator multipliers.

Part Time = Forming Time + Handling Time + Flip Time + Box Penalty
FileMaker Calculation — c_PartTime c_FormingTime + c_HandlingTime + c_FlipTime + c_BoxPenalty

13 Step 10: Difficulty Multiplier

Purpose: An overall complexity multiplier that accounts for factors beyond pure geometry — tight tolerances requiring test bends, awkward part shapes that slow the operator, or multiple tool setups.

FileMaker Calculation — c_DifficultyFactor Case ( DifficultyLevel = "Complex" ; 1.5 ; DifficultyLevel = "Moderate" ; 1.2 ; 1.0 )
Adjusted Time = Part Time × Difficulty Factor

14 Step 11: Second Operator Rule

Purpose: If the part is too heavy (>15 kg) or too long (>2000 mm), a second operator is required for safety. This doubles the labour cost because two people's time is being used.

FileMaker Calculation — c_OperatorMultiplier Let ( w = If ( PartWeight_kg > 0 ; PartWeight_kg ; c_AutoWeight_kg ) ; Case ( w > 15 or BendLength_mm > 2000 ; 2 ; 1 ) )
Total Labour Time = Adjusted Time × Operator Multiplier
= (Part Time × Difficulty Factor) × Operator Multiplier

15 Step 12: Final Seconds per Part

Purpose: Add packing time and apply the efficiency buffer to get the absolute final seconds per part.

FileMaker Calculation — c_FinalSecondsPerPart Let ( [ adjustedTime = c_PartTime * c_DifficultyFactor ; labourTime = adjustedTime * c_OperatorMultiplier ; withPacking = labourTime + PackingTime_sec ; effFactor = 1 + ( EfficiencyFactor_pct / 100 ) ] ; // If manual override is set, use it. Otherwise use calculated value. Case ( SecondsOverride > 0 ; SecondsOverride ; withPacking * effFactor ) )
Override Note: If SecondsOverride has a value greater than 0, the entire 12-step calculation is bypassed and the override value is used directly. This is for repeat jobs where the exact time is known from previous production.

16 Cost Calculation (Dollars)

Setup Cost

FileMaker Calculation — c_SetupCost Let ( setupHours = Case ( SetupUnit = "Hours" ; SetupTime ; SetupTime / 60 ) ; Round ( setupHours * HourlyRate ; 2 ) )

Example: 45 minutes ÷ 60 = 0.75 hours × $100 = $75.00

Labour Cost per Part (before setup)

FileMaker Calculation — c_LabourCostPerPart Round ( ( c_FinalSecondsPerPart / 3600 ) * HourlyRate ; 2 )

Cost per Part (with setup distributed)

Cost per Part = Labour Cost per Part + (Setup Cost ÷ Quantity)
FileMaker Calculation — c_CostPerPart Round ( c_LabourCostPerPart + ( c_SetupCost / Quantity ) ; 2 )

Key concept: Setup cost is paid once regardless of quantity. Making 10 parts? Each part carries $7.50 of setup. Making 1000 parts? Each carries only $0.075.

17 Optional Markups

Four optional checkboxes that add percentage markups to the total. They are cumulative (they add together, not compound).

CheckboxMarkupWhen to Tick
Stainless Steel+15%Material is stainless — harder on tooling, more springback
Complex Bends+10%Compound angles, acute bends, bends near holes
Multiple Setups+15%Part requires changing tools partway through the run
Tight Tolerance+10%Customer needs tighter than ±1mm
FileMaker Calculation — c_MarkupPercent If ( Markup_Stainless = "Yes" ; 15 ; 0 ) + If ( Markup_ComplexBends = "Yes" ; 10 ; 0 ) + If ( Markup_MultiSetup = "Yes" ; 15 ; 0 ) + If ( Markup_TightTolerance = "Yes" ; 10 ; 0 )

Final Total Cost

FileMaker Calculation — c_TotalCost Let ( [ baseCost = c_CostPerPart * Quantity ; markupMultiplier = 1 + ( c_MarkupPercent / 100 ) ] ; Round ( baseCost * markupMultiplier ; 2 ) )
FileMaker Calculation — c_FinalCostPerPart (after markup) Round ( c_TotalCost / Quantity ; 2 )

18 Manual Override

The SecondsOverride field allows the operator to bypass the entire 12-step calculation. If this field contains a value greater than 0, that value is used as the seconds per part directly.

When to use: Repeat jobs where production has been timed before. For example: "We made this part last month and it took exactly 45 seconds each."

This is already handled in the c_FinalSecondsPerPart formula above (the Case statement checks for SecondsOverride first).

19 Tooling Calculations

These are reference calculations that help the operator select the right tooling. They do not affect the cost.

V-Die Size

c_VDieSize_mm (already defined in Step 3a) Thickness_mm * 8 (or manual override)

Minimum Flange Length

The shortest flange the part can have without slipping into the die.

FileMaker Calculation — c_MinFlange_mm Round ( c_VDieSize_mm * 0.7 ; 1 )

Example: V-Die = 24mm × 0.7 = 16.8mm minimum flange

Required Tonnage

The force needed to bend the material. Must not exceed machine capacity.

FileMaker Calculation — c_Tonnage Let ( [ matFactor = Case ( Material = "Stainless Steel" ; 1.42 ; Material = "Aluminium" ; 0.50 ; 1.00 ) ; // Standard tonnage formula: (factor x thickness^2 x bend length) / V-die / 1000 tonnageKN = ( matFactor * Thickness_mm * Thickness_mm * BendLength_mm ) / c_VDieSize_mm ; tonnageT = tonnageKN / 1000 * 9.81 ] ; Round ( tonnageT ; 1 ) )
Note: This is an approximation. Actual tonnage depends on bend angle, material grade, and tooling profile. Always verify against the machine's tonnage chart.

20 Quantity Price Breaks

To show customers how the price drops with higher quantities. The only variable is how the setup cost is distributed — the labour per part stays the same.

Price per Part at Qty Q = Labour Cost per Part + (Setup Cost ÷ Q)
Total at Qty Q = Price per Part × Q
(Then apply markups if applicable)

In FileMaker, create a portal or repeating calculation for each break quantity:

For each Quantity Break (e.g., 10, 50, 100, 500, 1000) Let ( [ breakQty = 50 ; // change per row pricePerPart = Round ( c_LabourCostPerPart + ( c_SetupCost / breakQty ) ; 2 ) ; total = Round ( pricePerPart * breakQty ; 2 ) ; markupMultiplier = 1 + ( c_MarkupPercent / 100 ) ; finalPerPart = Round ( pricePerPart * markupMultiplier ; 2 ) ; finalTotal = Round ( finalPerPart * breakQty ; 2 ) ] ; // Display: breakQty & " parts: $" & finalPerPart & " each = $" & finalTotal finalPerPart )

21 Full Worked Example

Job: 200 × Stainless steel trays, 1500mm bend length, 4mm thick, 6 bends, 2 flips, Box geometry, Moderate difficulty, 8kg each, 10 sec packing, 10% efficiency, $100/hr, 45 min setup. Stainless markup ticked.

Step 1 — Base Bend Time (1500mm → 1001-2000mm)30 sec
Step 2 — Thickness Factor (4mm → 2.1-6mm)× 1.15
Step 3 — V-Die = 4 × 8 = 32mm → V-Die Factor (25-40mm)× 1.20
Step 4 — Bend Time = 30 × 1.15 × 1.2041.40 sec/bend
Step 5 — Forming Time = 41.40 × 6 bends248.40 sec
Step 6 — Handling Time (8kg → 5.1-10kg)+ 5 sec
Step 7 — Flip Time = 2 flips × 8 sec (1201-2000mm)+ 16 sec
Step 8 — Box Penalty = 41.40 × 0.5+ 20.70 sec
Step 9 — Part Time290.10 sec
Step 10 — Difficulty: Moderate× 1.2
      Adjusted Time = 290.10 × 1.2348.12 sec
Step 11 — 2nd Operator (8kg < 15kg, 1500mm < 2000mm)× 1 (no)
      + Packing+ 10 sec
      + Efficiency (10%)+ 35.81 sec
FINAL TIME PER PART393.93 sec (6.57 min)

Labour per Part = (393.93 ÷ 3600) × $100$10.94
Setup = (45 min ÷ 60) × $100 = $75.00 ÷ 200 parts+ $0.38
Cost per Part (before markup)$11.32
Stainless Markup +15%× 1.15

TOTAL JOB COST (200 parts)$2,603.00
